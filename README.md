# persona-page

Personal site for Josefa Lizama — Software Engineer, Santiago, Chile.

Next.js 16 (App Router) · React 19 · Tailwind CSS v4 · TypeScript · Nunito.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run start
npm run lint
```

## Content

All copy lives in [`app/data.ts`](app/data.ts) — `profile`, `skills`, `experience`, `projects`. Edit that file to update the site; the components just render it.

## Notes

- Design tokens (type scale, colors, radius, shadows) are in the `@theme` block of [`app/globals.css`](app/globals.css). Use them instead of one-off values.
- Text uses `gray-900` / `gray-700` / `gray-600`. `gray-400` and `gray-500` fail contrast at body size — borders and decoration only.
- The favicon is generated by [`app/icon.tsx`](app/icon.tsx), which is why `/icon` appears in the build output. There is no `public/`.
